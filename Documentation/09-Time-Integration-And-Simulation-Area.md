# 時間積分とシミュレーション領域

## 時間積分

粒子の速度と位置は、半陰解法の一種である半陰的オイラー法（シンプレクティック・オイラー法）で更新する。

```text
v(n + 1) = v(n) + a(n) Δt
x(n + 1) = x(n) + v(n + 1) Δt
```

位置の更新に更新後の速度を使う点が、通常の陽的オイラー法との違いである。

## 浅水波速度による速度制限

参照実装に合わせ、粒子速度を浅水波の伝播速度以下に制限する。

```text
c = √(gh)
```

- `c`：浅水波の伝播速度
- `g`：重力加速度
- `h`：流体深さ

流体深さは密度計算時に粒子ごとの`FluidDepth`へ保存し、時間積分や将来の描画処理から参照する。`Density`を更新した場合は、同じ密度計算処理内で`FluidDepth`も更新し、不整合を防ぐ。

## 境界処理

参照実装では、境界粒子と位置クランプを併用している。

- 境界粒子：近傍計算へ参加し、壁付近の密度や力を表現する。
- 位置クランプ：数値誤差や強い加速度による領域外への流出を防ぐ最終的な安全策とする。

境界粒子自身は時間積分せず、固定粒子として扱う。

## シミュレーション領域と初期流体領域

シミュレーション領域と、初期状態で流体粒子を配置する領域は分離する。

```text
Simulation Area
    粒子が移動できるゲーム上の領域

Particle Spacing
    シミュレーションの空間解像度

Initial Fluid Area
    初期状態で流体粒子を配置する領域
```

シミュレーション領域は正方形に限定せず、X方向とZ方向のサイズを個別に設定できるようにする。

## 採用する段階的な方針

現在は性能確認のため、`particleCountX`と`particleCountZ`をInspectorから直接指定できる状態を維持する。初期粒子の配置範囲は粒子数と粒子間隔から求め、シミュレーション領域は別の設定として持つ。

連続シミュレーションが動作した後、最終的には次の関係へ移行する。

```text
入力値：Simulation Area Size
入力値：Initial Fluid Area Size
入力値：Particle Spacing
計算値：X方向とZ方向の粒子数
```

粒子数と領域サイズを同時に独立した入力値にすると矛盾する可能性があるため、最終設計では領域サイズと粒子間隔を正とし、粒子数を計算結果とする。

## CFL条件による時間刻みの制限

半陰的オイラー法は陽的な時間積分であるため、時間刻みはCFL条件を満たす必要がある。SPH-SWEでは、粒子速度と浅水波の伝播速度を考慮する。

```text
Δt ≤ C_CFL h / (|u| + √(gH))
```

- `Δt`：1サブステップの時間
- `C_CFL`：Courant数。初期値は安全寄りの`0.25`とする。
- `h`：粒子の有効半径
- `|u|`：粒子速度の大きさ
- `g`：重力加速度
- `H`：粒子に保存された流体深さ

参照実装はCFL条件を動的に評価せず、固定時間刻み`0.002`を使用している。Unity版では`0.002`を時間刻みの固定上限とし、CFL条件がそれより厳しい場合は小さい値を採用する方針とする。

```text
使用する最大時間刻み
    = min(0.002, 全流体粒子から求めたCFL時間刻みの最小値)
```

必要なサブステップ数は、Unityの`Fixed Timestep`を最大安定時間刻みで割り、切り上げて求める。ただし、負荷の急増を防ぐ最大サブステップ数も必要になる。

最大サブステップ数へ到達した場合、単純に時間刻みを大きくするとCFL条件を破る。そのため、最終的には安定性を優先し、そのフレームで処理できなかったシミュレーション時間を次回へ持ち越す方式を検討する。持ち越し時間には上限を設け、処理落ちによる無制限な蓄積を防ぐ。

一般的なSPHでは、CFL条件に加えて加速度条件と粘性条件も使用する。現在の`viscosityCoefficient`を動粘性係数として直接使用できるか確認できるまでは、固定上限とCFL条件を先に採用し、加速度・粘性条件は後続の安定性改善として扱う。
