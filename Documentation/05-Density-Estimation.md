# 密度推定

## 基本式

粒子$i$の密度相当量を次で計算する。

$$
\rho_i
=
\sum_j m_j
W_{\mathrm{poly6}}
\left(
\lVert\mathbf{x}_i-\mathbf{x}_j\rVert,
h_i
\right)
$$

| 記号 | 意味 |
|---|---|
| $\rho_i$ | 粒子$i$の密度相当量 |
| $m_j$ | 粒子$j$の質量 |
| $\mathbf{x}_i$ | 計算対象粒子の位置 |
| $\mathbf{x}_j$ | 周辺粒子の位置 |
| $h_i$ | 粒子$i$の有効半径 |

実装上の加算は次となる。

```csharp
density += neighbor.Mass * kernelValue;
```

## 自己寄与

密度推定では`i == j`の自己寄与を含める。自分自身との距離は`0`であり、Poly6カーネルの重みは最大になる。

## 全粒子探索

最初は、各粒子について全粒子を確認する二重ループを基準実装とする。

計算量は次である。

$$
O(N^2)
$$

```text
256粒子  → 65,536組
4096粒子 → 16,777,216組
```

この実装は高速ではないが、後で空間グリッドによる近傍探索と結果を比較するために保持する。

## 構造体配列の更新

`SphSweParticle`は構造体である。配列要素を通常のローカル変数へ代入するとコピーになるため、密度を書き戻す対象には`ref`ローカルを使用する。

```csharp
ref var particle = ref particles[i];
particle.Density = density;
```

## 境界での密度低下

中央付近の粒子は近傍が多く、境界や角の粒子は近傍が少ない。そのため、境界粒子をまだ配置していない段階では、端へ近づくほど密度が低下する。

これは全粒子探索やPoly6の不具合ではない。後で境界粒子を導入して扱う。

## 検証項目

- 全密度が有限かつ正であること
- 中央付近の密度が境界より高いこと
- 同じ配置と設定で実行結果が再現すること
- 高速な近傍探索へ置き換えた後も、基準実装と十分近い結果になること

## 実装状況

全粒子探索による密度推定を実装中。粒子間距離の二乗は、`Vector2.sqrMagnitude`ではなく明示的な`float`乗算で計算する方針を採用した。
