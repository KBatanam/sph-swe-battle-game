# Spikyカーネル勾配

## Poly6とSpikyの役割分担

SPH-SWEでは、計算の目的に応じてカーネルを使い分ける。

| 計算対象 | 使用するカーネル | 主な理由 |
|---|---|---|
| 密度 | Poly6 | 中心付近を含めて滑らかで、距離の二乗から計算できる |
| 水面勾配 | Spikyの勾配 | 方向を持ち、粒子が接近しても勾配の大きさを保ちやすい |
| 粘性 | Viscosity | 近傍粒子との速度差を滑らかにする |

Poly6は、周囲に粒子がどれだけ存在するかを表すスカラー値の推定に使用する。

Spikyの勾配は、粒子分布がどの方向へ変化しているかを表すベクトルの推定に使用する。

## Poly6勾配の中心付近での性質

2次元Poly6カーネルは次の形である。

$$
W_{\mathrm{poly6}}(r,h)
\propto
(h^2-r^2)^3
$$

これを位置について微分すると、勾配は概ね次の形になる。

$$
\nabla W_{\mathrm{poly6}}(\mathbf{r},h)
\propto
-\mathbf{r}(h^2-r^2)^2
$$

勾配には位置差ベクトル$\mathbf{r}$が掛かっている。そのため、粒子間距離が`0`へ近づくと、Poly6勾配の大きさも`0`へ近づく。

$$
\lim_{r\to0}
\lVert\nabla W_{\mathrm{poly6}}\rVert
=0
$$

Poly6カーネルは中心で値が大きいが、山の頂上のように中心付近の傾きは小さい。

水面勾配や圧力に相当する加速度をカーネル勾配から求める場合、Poly6勾配では次の関係になる。

```text
粒子間距離が小さくなる
  ↓
Poly6勾配が小さくなる
  ↓
粒子間に生じる加速度も小さくなりやすい
```

したがって、非常に接近した粒子の位置がわずかに異なっていても、接近状態を解消する方向の反応が弱くなりやすい。

## Spikyカーネル勾配

参照実装が使用する2次元Spikyカーネル勾配は次である。

$$
\nabla W_{\mathrm{spiky}}(\mathbf{r},h)
=
-\frac{30}{\pi h^5}
(h-r)^2
\frac{\mathbf{r}}{r}
$$

| 記号 | 意味 |
|---|---|
| $\mathbf{r}$ | 対象粒子の位置から近傍粒子の位置を引いた位置差ベクトル |
| $r$ | $\lVert\mathbf{r}\rVert$で求める粒子間距離 |
| $h$ | カーネルの有効半径 |
| $\mathbf{r}/r$ | 位置差の方向を表す単位ベクトル |

Spiky勾配の大きさは次に比例する。

$$
\lVert\nabla W_{\mathrm{spiky}}\rVert
\propto
(h-r)^2
$$

$r$が`0`へ近づくと$(h-r)^2$は$h^2$へ近づく。そのため、勾配の大きさは`0`へ近づかない。

$$
\lim_{r\to0}
\lVert\nabla W_{\mathrm{spiky}}\rVert
=
\frac{30}{\pi h^3}
$$

これにより、粒子間距離が非常に小さい場合でも、位置がわずかに異なっていれば比較的強い勾配を計算できる。

## 完全に同じ位置の場合

Spiky勾配には次の単位ベクトルが含まれる。

$$
\frac{\mathbf{r}}{r}
$$

粒子が完全に同じ位置にある場合は$r=0$となり、方向を定義できない。これは、$r$が`0`へ近づく極限で勾配の大きさが維持されることとは別の問題である。

Unity実装ではゼロ除算を避けるため、距離が完全に`0`の場合はゼロベクトルを返す。

```csharp
if (squaredDistance <= 0f)
{
    return Vector2.zero;
}
```

正確な性質は次のように整理できる。

| 状態 | Poly6勾配 | Spiky勾配 |
|---|---|---|
| 粒子間距離が`0`へ近づく | 大きさも`0`へ近づく | 大きさを保ちやすい |
| 粒子間距離が完全に`0` | ゼロ | 方向を定義できないため実装上はゼロ |
| 有効半径以上 | ゼロ | ゼロ |

## 参照実装との対応

参照C++実装では、Spiky勾配の係数を次のように計算している。

```cpp
m_aspiky =
    -30.0f
    / (glm::pi<float>() * h * h * h * h * h);
```

カーネル勾配に相当する部分は次である。

```cpp
m_aspiky * q * q * rij / r
```

ここで`q = h - r`、`rij`が位置差ベクトルである。

## 実装方針

- `SphSweKernel`へ、`Vector2`を返すSpiky勾配関数を追加する。
- 距離の二乗は`sqrMagnitude`を使わず、明示的な`float`乗算で計算する。
- 有効半径が`0`以下なら、呼び出し側の不具合として例外を発生させる。
- 粒子間距離が完全に`0`なら`Vector2.zero`を返す。
- 有効半径以上なら、影響範囲外として`Vector2.zero`を返す。
- CPU基準実装で挙動を確認してからCompute Shaderへ移植する。
