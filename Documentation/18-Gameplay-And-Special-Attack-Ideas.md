# ゲームプレイと必殺技案

## 必殺技の基本仕様

- `Space`で選択中の必殺技を発射する。
- クールタイムは5秒とする。
- ゲーム開始時はクールタイムが完了しておらず、必殺技を発射できない。
- 画面右下に残り時間を数字で表示し、クールタイム完了後は「発射可能」と表示する。
- `W`と`S`による必殺技の切り替えは、複数の必殺技を実装する段階で追加する。

## 必殺技候補

1. 電撃攻撃
   - 最初に実装する必殺技とする。
2. 移動速度アップ
3. 波の大きさアップ

必殺技の具体的な効果量と持続時間は、実際のゲームプレイを確認しながら調整する。

## 簡易Enemy AI

Enemyは、既存の移動、波生成および雷砲コンポーネントを`EnemyController`から操作する。Player入力とAIで実際の行動処理を共有し、将来ネットワーク入力へ置き換える場合も同じ公開APIを利用する。

行動の優先順位は次のとおりとする。

1. 雷砲のクールタイムが完了したら、PlayerのX位置へ移動する。照準が許容範囲内に入った時点で雷砲を発射する。
2. 雷砲を発射できず、目的球が中央へ近づいた場合は、Enemy側へ入る前から目的球のX位置へ移動する。
3. 目的球が波の影響範囲へ入ったら、短いランダム間隔で波を繰り返し発生させ、Player側へ押し返す。
4. 攻撃と防御のどちらも必要ない間は、移動可能範囲内からランダムなX目標を選び、その目標間を巡回する。

硬直中の移動、波生成および雷砲発射の拒否は、それぞれの既存コンポーネントが担当する。AI側で同じ硬直判定を重複して持たない。

初期調整値：

```text
Attack Horizontal Alignment Tolerance: 0.2
Wave Horizontal Alignment Tolerance: 0.45
Patrol Boundary Inset: 0.25
Wave Defense Activation Distance Before Center: 0.75
Minimum Wave Generation Interval: 0.08
Maximum Wave Generation Interval: 0.14
Enemy Wave Impulse Strength: 2
```

このAIは対戦挙動を確認するための簡易実装であり、難易度調整、予測照準および行動パターンの高度化は今後のゲームプレイ結果に応じて行う。

### 動作確認

2026年9月30日にUnity Editor上で次を確認した。

- Enemyが左右へ移動し、X座標が初期値`0`から変化する。
- 目的球がEnemy側にある間、EnemyからPlayer方向である`-Z`へ波を繰り返し発生させる。
- 雷砲のクールタイム完了後、Playerへ横方向の照準を合わせて発射する。
- 雷砲がPlayerへ命中し、1秒の硬直が適用される。
- Consoleに例外、コンパイルエラーおよび実行時Warningが発生しない。

防御開始位置、波間隔、横方向の許容範囲および波強度を調整した後の再検証では、約30秒間に防御波を8回発生させ、目的球をEnemy側へ通さずPlayer側の`Z=-2.49`まで押し戻した。Enemyの横移動とPlayerへの雷砲命中も継続して確認した。

## 左右端からの環境平面波

目的球が左右端へ寄ったまま前後方向にしか移動しなくなる状況を防ぐため、左右端から定期的に環境平面波を発生させる方針とする。

採用方針：

- 発生間隔の初期値は2秒とする。
- 目的球が右側にある場合は、シミュレーション領域の右端に沿った帯状領域の全流体粒子へ`-X`方向の速度を与える。
- 目的球が左側にある場合は、左端に沿った帯状領域の全流体粒子へ`+X`方向の速度を与える。
- Z方向の一部分だけに円形の波を発生させず、端の全Z範囲から中央へ進む平面波とする。
- 中央付近には判定のデッドゾーンを設け、わずかな左右移動によって波の発生側が頻繁に切り替わらないようにする。
- PlayerとEnemyが発生させる波とは別の環境システムとして実装する。

`FluidDepth`は密度計算から毎サブステップ再計算されるため、キャッシュ値を直接変更しても次の密度計算で上書きされる。Massの変調は密度校正と復元管理へ影響するため、最初の実装では使用しない。左右端の帯状領域へ内向き速度を一括付与することで、現在のMassと密度計算を維持したまま平面波を作る。

この環境平面波は後で実装し、帯の幅、発生間隔、速度変化量および中央デッドゾーンはゲームプレイを確認しながら調整する。

## 実装後の更新（2026年9月30日）

この節は、上に記録された初期案より新しい正式な実装状態を表す。

### 環境平面波

左右端からの環境平面波は`PeriodicSideWaveController`として実装済みである。

- 目的球が右側にある場合は右端から`-X`方向へ発生する。
- 目的球が左側にある場合は左端から`+X`方向へ発生する。
- 初期間隔は2秒とする。
- 円形の局所波ではなく、端の全Z範囲にある流体粒子へ内向き速度Impulseを与える。

### Enemy AI

初期AIでは、目的球がPlayer側へ移動すると防御波を停止し、雷砲はPlayerの現在位置を発射直前まで追跡していた。この挙動では攻撃波が不足し、雷砲がほぼ必中となったため、次の方式へ更新した。

1. 目的球がEnemy側にある場合は、`0.08～0.14`秒間隔で防御波を発生させる。
2. 目的球がPlayer側にある場合も、`0.3～0.5`秒間隔で攻撃波を発生させる。
3. 雷砲を準備していない間は、目的球のX位置へ移動して造波位置を合わせる。
4. 雷砲の使用準備ができた時点で照準X位置を固定し、発射直前までPlayerを追跡し続けない。
5. `0.8～1.1`秒の照準時間を設け、その間にPlayerが移動すれば回避可能とする。
6. 初期命中照準確率を`0.6`とし、命中を狙わない場合は左右へ`0.9～1.4`ずらして明確に外す。

雷砲の実際の命中範囲には、雷砲Hit Boxの半幅だけでなくPlayer Colliderの半幅も加わる。小さな照準誤差では命中率がほとんど下がらないため、外す場合のOffsetは合成された当たり幅より大きくする。

これらは簡易AIの難易度調整値であり、ゲームプレイ結果に応じてInspectorから変更する。硬直中の行動拒否は引き続き各行動コンポーネントが担当する。
