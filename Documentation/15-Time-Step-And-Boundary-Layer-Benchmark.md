# 時間刻みと境界粒子層数の比較

## 目的

最大時間刻みと境界粒子層数を変更し、計算時間と短時間の数値的安定性を比較した。

Editor拡張として次のメニューを追加した。

```text
Tools > SPH-SWE > Benchmarks > Run Time Step and Boundary Layer Benchmark
```

Play Mode中に実行すると、次の8条件を同じ初期状態から比較する。

```text
Maximum Simulation Time Step:
0.002 / 0.003 / 0.004 / 0.005秒

Boundary Particle Layer Count:
2 / 3層
```

各条件では仮想的な`0.02`秒を10フレーム、合計`0.2`秒進める。CPU時間、サブステップ数、粒子数、密度範囲、最大速度、非有限値を持つ粒子数、処理未完了フレーム数を記録する。

## 測定結果

| 境界層数 | 最大時間刻み | 境界粒子数 | サブステップ合計 | 平均CPU時間 |
|---:|---:|---:|---:|---:|
| 2 | 0.002 | 960 | 100 | 13.98 ms |
| 2 | 0.003 | 960 | 70 | 9.78 ms |
| 2 | 0.004 | 960 | 50 | 6.97 ms |
| 2 | 0.005 | 960 | 40 | 5.59 ms |
| 3 | 0.002 | 1452 | 100 | 27.15 ms |
| 3 | 0.003 | 1452 | 70 | 18.35 ms |
| 3 | 0.004 | 1452 | 50 | 13.32 ms |
| 3 | 0.005 | 1452 | 40 | 10.60 ms |

全条件で次の結果となった。

```text
Invalid Particle Count = 0
Incomplete Virtual Frame Count = 0
Maximum Fluid Velocity ≈ 1.401
```

## 境界粒子層数

現在の粒子間隔と固定有効半径では、シミュレーション領域内の最初の流体粒子列から3層目の境界粒子までの距離は有効半径以上になる。

壁際へ流体粒子を配置して密度を測定したところ、次の結果になった。

```text
2層の壁際密度 = 483.40
3層の壁際密度 = 483.40
```

現在の配置条件では、3層目は壁際粒子の密度計算へ寄与していない。2層化により境界粒子数は`1452`から`960`へ減少し、同じ時間刻みにおけるCPU時間は概ね半減した。

したがって、現在の固定有効半径と粒子間隔では、境界粒子を2層へ減らすことが妥当である。

## 最大時間刻み

参照実装の固定時間刻みは`0.002`秒である。Unity版で時間刻み上限を大きくすると参照実装との差は増えるが、Unity版には粒子状態に応じたCFL制限がある。

短時間試験では`0.005`秒まで非有限値や処理未完了は発生しなかった。ただし、静かな初期状態を`0.2`秒進めただけであり、長時間の波動、強い加速度、壁衝突に対する安定性は保証しない。

現時点の推奨試験値は、性能を約2倍へ改善しながら`0.005`より安全側に余裕を残す`0.004`秒とする。

```text
推奨する次の試験設定:
Maximum Simulation Time Step = 0.004
Boundary Particle Layer Count = 2
```

この設定を正式採用する前に、長時間の波動試験とProfilerによる実フレーム計測を行う。

## 採用結果

比較結果に基づき、`Boundary Particle Layer Count = 2`を正式な初期設定として採用した。Sceneの設定とスクリプトのデフォルト値をともに2層へ変更した。

`Maximum Simulation Time Step`は、この変更には含めず`0.002`秒のままとする。

## 長時間安定性試験

`0.004`秒を正式採用できるか判断するため、Editor拡張へ次のメニューを追加した。

```text
Tools > SPH-SWE > Benchmarks > Run Long Time Step Stability Benchmark
```

流体領域の左右で粒子質量を`1.5倍`と`0.5倍`に分け、中心へ向かう`1.5`の初速を与えることで、静止状態より強い密度差と速度変化を発生させた。同じ初期状態から`0.002`秒と`0.004`秒をそれぞれ5秒間計算した。

| 最大時間刻み | サブステップ数 | CPU時間 | 観測密度範囲 | 最大速度 | CFL制限回数 | 無効粒子数 |
|---:|---:|---:|---:|---:|---:|---:|
| 0.002 | 2500 | 3817.65 ms | 99.83～1205.98 | 3.014 | 0 | 0 |
| 0.004 | 1250 | 1938.59 ms | 99.83～1200.76 | 2.941 | 0 | 0 |

`0.004`秒では、サブステップ数とCPU時間がほぼ半分になった。5秒間の試験中にNaNまたはInfinityを持つ粒子は発生せず、CFL条件が`0.004`秒より小さな時間刻みを要求する場面もなかった。

両条件の最大密度差は約`0.43%`、最大速度差は約`2.4%`だった。この差は時間離散化による誤差として残るため、参照実装との厳密な一致よりリアルタイム性能を優先する設定として扱う。

この結果から、現在のCPU版における`Maximum Simulation Time Step = 0.004`は、次の実動作試験へ進める妥当な候補と判断する。Scene設定は正式採用の判断が行われるまで`0.002`秒へ戻している。

## 最大時間刻みの正式採用

長時間安定性試験の結果に基づき、`Maximum Simulation Time Step = 0.004`秒を正式採用した。Sceneの設定とスクリプトのデフォルト値をともに`0.004`秒へ変更した。

参照実装の固定時間刻み`0.002`秒は比較用の基準として残す。Unity版ではCFL条件による動的な時間刻み制限を併用し、粒子速度または流体深さが増加した場合は`0.004`秒より小さな時間刻みを選択する。
