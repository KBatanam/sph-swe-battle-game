# パラメータ校正とデバッグ用造波

## 背景

境界粒子の質量を正弦波状に変化させるデバッグ用造波を実装し、流体粒子がそれらしく運動することを確認した。

ただし、現在のUnity実装では、初期状態の流体粒子の平均密度が参照密度と大きく異なっている。

```text
参照密度: 998.29
現在の実測平均密度: 約16
```

流体深さは密度相当量を参照密度で除算して求めるため、現在の平均流体深さは約`0.016`となる。

$$
d_i=\frac{\rho_i}{\rho_0}
$$

| 記号 | 意味 |
|---|---|
| $d_i$ | 粒子$i$の流体深さ |
| $\rho_i$ | SPHで推定した密度相当量 |
| $\rho_0$ | 参照密度 |

このスケール差により、参照実装と同じ粘性係数や造波パラメータを設定しても、同じ挙動にはならない。

## 密度校正の方針

参照実装では、粒子質量、有効半径内の目標粒子数、参照密度から有効半径を計算している。

$$
h=\sqrt{\frac{mN_k}{\pi\rho_0}}
$$

さらに、粒子半径と粒子間隔を有効半径から決定している。

$$
r_p=\frac{1}{2}h\sqrt{\frac{\pi}{N_k}}
$$

$$
\Delta x=2r_p
$$

| 記号 | 意味 |
|---|---|
| $h$ | 有効半径 |
| $m$ | 粒子質量 |
| $N_k$ | 有効半径内の目標粒子数 |
| $\rho_0$ | 参照密度 |
| $r_p$ | 粒子半径 |
| $\Delta x$ | 粒子間隔 |

Unity版でも、これらを独立した無関係なInspector値として扱うのではなく、参照実装の依存関係へ可能な限り合わせる。

校正後は、平衡状態にある流体粒子の平均密度が参照密度付近になることを実測して確認する。式だけでは格子配置、境界粒子、カーネル実装の差が残る場合、次の比率を使った質量補正も検討する。

$$
m_{\mathrm{corrected}}
=m_{\mathrm{current}}
\frac{\rho_0}{\bar{\rho}_{\mathrm{measured}}}
$$

現在の平均密度を約`16`、粒子質量を`1`とすると、暫定的な補正質量は約`64`となる。ただし、これは最終決定値ではなく、参照実装のパラメータ依存関係を再現した後に再測定する。

## 有効半径の設計方針

参照実装には、密度に応じて粒子ごとの有効半径を更新する処理が存在する。

今回のUnity実装では、**動的可変有効半径を採用しない**。

```text
採用する方針:
全粒子で共通の固定有効半径を使用する

採用しない方針:
密度に応じて粒子ごとの有効半径を動的に変更する
```

理由は次のとおり。

- 実装と検証の複雑化を避ける。
- 近傍探索のセルサイズと探索範囲を一定に保てる。
- CPU版と将来のGPU版でデータ構造を単純に保てる。
- 密度校正、粘性、時間刻みなど、他の原因との切り分けを容易にする。

したがって、参照実装へ合わせる際も、初期状態で一度決定した共通有効半径をシミュレーション中は変更しない。

## デバッグ用境界造波

指定した辺の境界粒子について、初期質量を中心とする正弦波状の質量変化を継続的に与える。

$$
m_b(t)=m_{b,0}\left(1+A\sin(2\pi ft)\right)
$$

| 記号 | 意味 |
|---|---|
| $m_b(t)$ | 時刻$t$における境界粒子の質量 |
| $m_{b,0}$ | 境界粒子の初期質量 |
| $A$ | 質量振幅 |
| $f$ | 周波数 |

参照実装の式では質量が負になる時間帯があるため、Unity版では初期質量を中心に振動させ、振幅を`0.99`以下へ制限する。

デバッグ用造波は、物理的に閉じた系の質量保存を再現する処理ではない。領域外部の造波装置からエネルギーと質量相当の影響を入力するデバッグ機能として扱う。

動作確認では次の強い設定を使用した。

```text
Debug Boundary Wave Mass Amplitude = 0.99
Debug Boundary Wave Frequency = 0.5
Viscosity Coefficient = 0
Fluid Depth Gizmo Height Scale = 100
Particle Acceleration Gizmo Drawing Enabled = true
```

この設定で運動が確認できたため、造波、密度計算、勾配加速度、積分までの計算経路は機能している。なお、この造波機能はデバッグ用途であり、現時点ではリポジトリへpushしない方針とする。

## 次の検証順序

1. 参照実装の粒子質量、目標近傍粒子数、参照密度の関係をUnity版へ反映する。
2. 共通の固定有効半径と粒子間隔を決定する。
3. 造波を停止した平衡状態で平均密度を測定する。
4. 平均密度が参照密度付近になるよう粒子質量を校正する。
5. 流体深さ、浅水波速度、CFL時間刻みを再確認する。
6. 粘性係数を`0`から段階的に増やし、減衰量を調整する。
7. 必要に応じてデバッグ造波の振幅と周波数を再調整する。

## 密度校正の実装結果

参照実装と同じ基準値を使用し、粒子質量と目標近傍粒子数から、全粒子共通の固定有効半径、粒子半径、粒子間隔を計算する処理を実装した。

```text
Particle Mass = 2.0
Kernel Particle Count = 20
Reference Density = 998.29

Effective Radius = 0.112935
Particle Radius = 0.022380
Particle Spacing = 0.044760
```

初期配置を生成して密度を計算した結果、流体領域の中心に最も近い粒子の密度は`992.40`となった。参照密度`998.29`に対する相対誤差は約`0.59%`であり、許容誤差`2%`以内に収まっている。

一方、現在の小さな`5 × 5`流体粒子配置では、全粒子の平均密度は約`779.38`となる。流体領域の端にある粒子は、領域外側に流体粒子が存在せず、有効半径内の近傍粒子が不足するためである。

したがって、現在の校正では次の基準を使用する。

```text
校正基準:
近傍粒子が十分に存在する流体領域内部の粒子密度

校正基準にしない値:
自由端を多数含む小さな流体領域全体の平均密度
```

この結果により、以前の`平均密度が約16`という状態は、参照実装の粒子間隔と有効半径の依存関係を反映することで解消された。現時点では追加の質量補正を行わない。

有効半径は初期化時に共通値として計算し、シミュレーション中は変更しない。動的可変有効半径は引き続き採用しない。

## 密度校正後のテスト結果

次の処理が密度校正後のパラメータでも正常に動作することをUnity Editor上で確認した。

- 参照粒子パラメータの計算
- 流体深さ勾配加速度
- 粘性加速度
- 空間グリッドと全粒子探索の密度計算結果の一致
- Poly6カーネルとSpikyカーネル勾配
- 空間グリッドによる近傍探索
- 半陰的オイラー法による時間積分
- CFL条件を使用する時間刻み
- 境界粒子とシミュレーション領域のクランプ
